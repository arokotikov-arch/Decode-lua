# 🎯 ablua — активатор PC-версий Angry Birds

Небольшая программа, которая делает за вас всю ручную работу из гайда
[«How to activate PC games (2024)»](https://angrybirds.fandom.com/wiki/User_blog:ChickenLover21/How_to_activate_PC_games_(2024))
с Angry Birds Wiki:

* снимает шифрование с `data/scripts/options.lua`;
* распаковывает контейнер (7z или LZMA);
* выключает `gamelua.g_registrationEnabled` и `gamelua.g_updateCheckEnabled`;
* упаковывает файл обратно и шифрует тем же ключом;
* **проверяет результат** и оставляет резервную копию `*.ablua.bak`.

В отличие от ручного способа не нужны AB360 LUA Manager, `7za.exe`, Java и
`unluac`: правка идёт **прямо в байткоде Lua 5.1** (или в исходнике, если он
текстовый), а 7z-архивы читаются и пишутся собственной реализацией формата.

## Быстрый старт

### Windows

1. Установите [Python 3](https://www.python.org/downloads/) (при установке
   отметьте галочку **Add Python to PATH**). Никаких дополнительных библиотек
   не нужно.
2. Скачайте этот репозиторий (кнопка **Code → Download ZIP**) и распакуйте.
3. Запустите двойным кликом:

   * `START-Activator.bat` — пошаговый мастер;
   * `START-Activator-Admin.bat` — то же, но сразу с правами администратора
     (нужны, если игра стоит в `Program Files`);
   * `START-GUI.bat` — интерфейс в браузере.

4. В мастере выберите найденную игру → подтвердите → запускайте игру.

### Командная строка (Windows / Linux / macOS)

```bash
python ablua.py                  # пошаговый мастер
python ablua.py scan             # найти установленные игры
python ablua.py activate "C:\Program Files (x86)\Rovio Entertainment Ltd\Angry Birds"
python ablua.py activate --all   # активировать все найденные игры
python ablua.py restore "C:\...\Angry Birds\data\scripts\options.lua"
python ablua.py gui              # интерфейс в браузере
```

Если игра установлена в нестандартное место:

```bash
python ablua.py activate "D:\Games\Angry Birds Rio"
python ablua.py scan --root "D:\Games"
```

### Тренировка на демо-файлах

В репозитории есть папка `demo/` — две «игрушки» с такими же по структуре
файлами, но без настоящих данных. На них удобно посмотреть, как всё работает:

```bash
python ablua.py info   "demo/Angry Birds/data/scripts/options.lua"
python ablua.py activate "demo/Angry Birds" --dry-run   # только показать план
python ablua.py activate "demo/Angry Birds"             # изменить файл
python ablua.py restore  "demo/Angry Birds/data/scripts/options.lua"
```

Пересобрать демо-файлы в исходное состояние: `python tools/make_demo.py`.

## Что именно делает программа

Пошагово, для файла `data/scripts/options.lua`:

| Шаг | Что делает программа | Что делал гайд руками |
|-----|----------------------|------------------------|
| 1 | Читает файл и **сам подбирает ключ** (по названию папки, затем перебором всех известных) | выбирал игру в списке LUA Manager |
| 2 | Снимает AES-256-CBC (ключ 32 символа, IV = нули) | кнопка «Decrypt» |
| 3 | Определяет контейнер: 7z, LZMA или «как есть» | проверял первые байты |
| 4 | Находит флаги `g_registrationEnabled` / `g_updateCheckEnabled` и превращает `true` в `false` | «Decode» → правка текста руками |
| 5 | Собирает файл обратно в тот же контейнер и шифрует тем же ключом | «Encrypt» + 7z |
| 6 | Создаёт копию `options.lua.ablua.bak` и кладёт результат на место | делал копию вручную |
| 7 | Расшифровывает результат и сверяет флаги | проверял запуском игры |

Флаги правятся **точечно**:

* если файл текстовый — заменяются только присваивания этих двух флагов
  (в комментариях и строках ничего не трогается, кодировка файла сохраняется);
* если это байткод Lua 5.1 — меняются инструкции `LOADBOOL` или ссылки на
  константу `true`, при этом другие `true` в файле (например,
  `g_soundEnabled = true`) остаются включёнными.

Поддерживаемые игры и ключи:

| Игра | Ключ (ID для `--game`) |
|------|------------------------|
| Angry Birds (классика) | `classic` |
| Angry Birds Rio | `rio` |
| Angry Birds Seasons | `seasons` |
| Angry Birds Space | `space` |
| Angry Birds Star Wars | `starwars` |
| Angry Birds Star Wars II | `starwars2` |
| Angry Birds Friends | `friends` |

Если у вашей версии игры другой ключ, его можно передать вручную:

```bash
python ablua.py activate "D:\Games\Angry Birds" --key 55534361505170413454534E56784D49317639534B39554330795A75416E6232
python ablua.py activate "D:\Games\Angry Birds" --key USCaPQpA4TSNVxMI1v9SK9UC0yZuAnb2
```

Ключ принимается как в виде текста (32 символа), так и в hex (64 цифры).

## Команды

```
python ablua.py scan [--root ПАПКА]              найти установленные игры и показать статус
python ablua.py info ФАЙЛ                        подробный разбор файла (игра, контейнер, флаги)
python ablua.py decrypt ФАЙЛ [-o КУДА]           расшифровать и распаковать (для изучения)
python ablua.py encode ФАЙЛ -o КУДА --game ID    зашифровать подготовленный файл
python ablua.py activate ПУТЬ [--all] [--dry-run] выключить регистрацию и проверку обновлений
python ablua.py restore ФАЙЛ                     вернуть файл из *.ablua.bak
python ablua.py gui [--port 8765]                локальный веб-интерфейс
python ablua.py wizard                           пошаговый режим
```

Общие параметры (можно указывать до или после команды):

| Параметр | Смысл |
|----------|-------|
| `--key КЛЮЧ` | свой ключ (32 символа или 64 hex-цифры) |
| `--game ID` | считать файл принадлежащим этой игре |
| `--dry-run` | показать, что будет сделано, но ничего не писать |
| `--no-backup` | не создавать резервную копию |
| `--root ПАПКА` | где искать игру (для `scan` и `activate`) |
| `--all` | обработать все найденные игры |

Коды возврата: `0` — успех, `1` — ошибка/ничего не найдено, `130` — прервано.

## Веб-интерфейс

```bash
python ablua.py gui                 # откроется http://127.0.0.1:8765/
python ablua.py gui --root "D:\Games" --port 9000
```

Что можно делать мышкой:

* увидеть список найденных игр и статус («нужна активация» / «уже активировано»);
* открыть `options.lua`, посмотреть расшифрованный текст и текущие флаги;
* нажать **«Активировать»** (создаётся резервная копия) или **«Откатить»**;
* отредактировать текст в окне и нажать **«Сохранить правку в файл»**;
* нажать большую кнопку **«LET'S GOOO!»**, чтобы активировать всё сразу;
* побродить по каталогам и открыть любой файл.

По умолчанию сервер слушает только `127.0.0.1` и работает исключительно внутри
каталога, из которого запущен (защита от «залезть куда не просили»). Расширить
доступ: `--root ПАПКА`.

## Как это устроено внутри

```
options.lua на диске
      │  AES-256-CBC (ключ игры, IV = 16 нулевых байт, PKCS#7)
      ▼
7z-архив  /  LZMA-поток  /  данные как есть
      │  распаковка (свой разбор 7z: Copy, LZMA1, LZMA2, BCJ x86, Delta,
      │  solid-блоки, сжатые заголовки)
      ▼
байткод Lua 5.1  или  исходный текст  или  JSON
      │  правка флагов
      ▼
упаковка + шифрование тем же ключом → проверка → запись
```

Полезные детали реализации:

* **`abluatool/aes.py`** — AES-256-CBC и PKCS#7 на чистом Python (совпадает с
  `openssl enc -aes-256-cbc -K <ключ> -iv 00` до байта, проверено тестами).
  Если установлены `cryptography` или `pycryptodome`, используется быстрый путь.
* **`abluatool/sevenzip.py`** — минимальный, но полноценный 7z: чтение
  многофайловых и «solid» архивов, поддержка `LZMA1`, `LZMA2`, `BCJ x86`,
  `Delta`, `Copy`, сжатых (encoded) заголовков; запись однoфайлового архива
  с LZMA2 и корректными CRC.
* **`abluatool/luafmt.py`** — разбор чанка Lua 5.1 (заголовок, прототипы,
  константы, инструкции) и точечная правка:
  * значение грузится `LOADBOOL` → в инструкции меняется бит `B`;
  * значение берётся из таблицы констант → константа переворачивается, если на
    неё больше никто не ссылается, иначе в таблицу добавляется отдельная
    константа `false`, а присваивание переводится на неё (другие `true` в файле
    остаются `true`).
* **`abluatool/engine.py`** — подбор ключа с проверкой правдоподобности
  результата (случайный ключ может дать «валидное» дополнение PKCS#7 с шансом
  ~1/256, поэтому содержимое дополнительно оценивается), резервные копии,
  атомарная запись, проверка после записи.
* **`abluatool/games.py`** — поиск установок в
  `C:\Program Files (x86)\Rovio Entertainment Ltd\…`, `C:\Program Files\…`,
  `%LOCALAPPDATA%\Rovio`, `?: \Games`.

## Если что-то пошло не так

**«Нет прав на запись»**
Игра стоит в `Program Files`. Запустите `START-Activator-Admin.bat` или
командную строку от имени администратора.

**«Не удалось расшифровать файл ни одним известным ключом»**
Проверьте, что это действительно `data/scripts/options.lua` из PC-версии
Angry Birds (а не файл сохранения), и укажите ключ вручную через `--key`.
Если файл уже расшифрован кем-то раньше, программа так и скажет — тогда
достаточно указать игру (`--game classic`), чтобы запаковать его обратно.

**«В таблице констант уже 256 элементов»**
Экзотика: в этом конкретном чанке нельзя добавить константу `false`. Варианты:
правьте текстовую версию файла (`decrypt` → правка → `encode`) или сообщите о
таком файле в issue.

**Игра всё ещё просит регистрацию**
Проверьте командой `python ablua.py info "путь\options.lua"` — флаги должны быть
`false`. Если их нет в файле вообще, значит у вашей сборки другой `options.lua`
или игра берёт настройки из другого места.

**Хочу вернуть всё как было**
`python ablua.py restore "путь\options.lua"` — вернёт файл из `*.ablua.bak`.
Копия создаётся автоматически перед первой правкой.

**Антивирус/Defender шумит**
Программа не качает и не устанавливает ничего из интернета, а правит один
локальный файл. Если Defender ругается на `.bat`, запускайте команды вручную
через `python ablua.py …`.

**Где взять саму игру, если она не установлена**
Дистрибутивы PC-версий сохранились в веб-архиве:
<https://web.archive.org/web/20131217034005/download.angrybirds.com> (ссылка из
гайда). Этот репозиторий игры не распространяет.

## Разработка и тесты

```bash
python -m unittest discover -s tests -v     # 51 тест
python tools/make_demo.py                   # пересобрать demo/
```

Тесты проверяют:

* AES против векторов NIST SP 800-38A и против `openssl` (если он есть в системе);
* собственный 7z против независимой библиотеки `py7zr` (если установлена):
  и запись, и чтение (включая сжатые заголовки, BCJ и solid-архивы);
* правку байткода на настоящем чанке Lua 5.1 (если в системе есть `lua` —
  пропатченный чанк ещё и запускается, чтобы убедиться в корректности);
* сквозной сценарий: расшифровка → правка → упаковка → шифрование → проверка →
  откат, идемпотентность, `--dry-run`, ошибочные ситуации.

Структура репозитория:

```
ablua.py                     точка входа
abluatool/                   библиотека и интерфейсы
  aes.py  sevenzip.py  containers.py  luafmt.py  engine.py  games.py  keys.py
  cli.py  webui.py  web/index.html
tests/                       автотесты + фикстуры (настоящий байткод Lua 5.1)
tools/make_demo.py           сборка тренировочных файлов
demo/                        тренировочные «установки» игр
START-Activator*.bat         запуск для Windows
```

Требуется только Python 3.8+. Внешние зависимости — опциональные
(`py7zr` и интерпретатор `lua` используются исключительно в тестах).
